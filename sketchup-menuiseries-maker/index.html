SketchupMenuiseriesMaker

Un outil pour générer des menuiseries extérieures à fabriquer soi-même avec seulement des outils électro-portatifs.

Présentation

SketchupMenuiseriesMaker est une extension pour SketchUp qui génère automatiquement les pièces d'une menuiserie extérieure (bâti, tableau, seuil, jointures) à partir des dimensions d'une ouverture, prêtes à être découpées et assemblées avec des outils électro-portatifs classiques.

Installation

  1. Télécharger le fichier .rbz ci-dessous.
  2. Dans SketchUp : Fenêtre → Gestionnaire d'extensions → Installer une extension, puis sélectionner le fichier téléchargé.

Télécharger la dernière version (.rbz)

Développement

Le code source est disponible sur GitHub (licence MIT).

Pour lancer les tests unitaires :

ruby tests/runner

Pour travailler sur l'extension sans réinstaller le .rbz à chaque changement, suivre le guide de configuration pour le développement de SketchUp, puis recharger l'extension depuis la console Ruby avec :

I3D::MenuiseriesExterieures.reload
