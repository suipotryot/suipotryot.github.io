SketchupMenuiseriesMaker

A tool to generate exterior joinery you can build yourself with nothing but power tools.

Overview

SketchupMenuiseriesMaker is a SketchUp extension that automatically generates the parts of an exterior frame (frame, reveal, sill, joints) from the dimensions of an opening, ready to be cut and assembled with standard power tools.

Installation

  1. Download the .rbz file below.
  2. In SketchUp: Window → Extension Manager → Install Extension, then pick the downloaded file.
